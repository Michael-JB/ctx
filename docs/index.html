❯ ctx

Frictionless context-switching, in the terminal setup you already have.

ctx is a TUI and CLI for managing repo-scoped work contexts: each context is a fresh full checkout on its own local branch, wrapped in a terminal multiplexer session with your panes already laid out. Spin one up per task, jump between them, archive them when you're done.

$ uv tool install ctx-tui

Agents let you work on several things at once. ctx takes the friction out of switching between them.

Fresh checkouts, not worktrees

Every context is a full clone on its own branch, cut from the up-to-date default branch. No shared state, nothing to untangle: ctx rm and it's gone.

Sessions laid out your way

ctx is unopinionated about your setup. You describe the panes a context opens with (editor, git client, an agent, anything) and every session comes up that way, in the multiplexer you already use.

Status at a glance

Status columns are pluggable. Git state is built in; add PR status, agent state (working, idle, blocked), or integrate your own.

Agent-native

Agents know how to use ctx. With the skill installed, they can manage contexts themselves: tell one to do something in a new ctx and it spins one up, works in there, and wraps up when it's done.

Get started

$ uv tool install ctx-tui
$ ctx repo add https://github.com/you/your-repo.git
$ ctx

That last command opens the TUI, where everything happens: create, open, archive (? lists the keys). Zero config required; see the README for layouts, status columns, and agent hooks.
